# Galaxian Clone 

A modern reimplementation of the classic **Galaxian** arcade game using **C++** and the **SDL2 library**.  
This project was built to strengthen my understanding of **object-oriented programming**, **event-driven systems**, and **real-time rendering**.

## Features
- **Player controls**: Smooth ship movement and responsive shooting mechanics.
- **Enemy waves**: Dynamic spawning patterns and attack behaviors modeled after the original Galaxian.
- **Collision detection**: Accurate hitbox detection between lasers, enemies, and the player ship.
- **Game loop**: Real-time updates with SDL for rendering, input handling, and frame control.
- **Scoring system**: Tracks player points based on enemy kills.

## Why This Project
I built this clone to explore:
- **Object-oriented design** in games (inheritance, polymorphism, reusable entities).
- **Event-driven programming** with SDL for input, rendering, and updates.
- **Performance trade-offs** in real-time systems.
